StayFinder is a client-side accommodation search demo with advanced filters (amenities, property type, review score). Built with plain HTML/CSS/vanilla JavaScript — no build tools or npm required.

## How to run

Open index.html directly in any browser (Chrome, Firefox, or Edge). No server or installation needed.

## Files

- **index.html** — main application page with search UI and results
- **tests.html** — in-browser test suite for the application logic
- **requirements.md** — functional and non-functional requirements for the project
- **architecture.md** — technical architecture and component design overview
- **design-review.md** — design decisions, trade-offs, and review notes
- **impl-plan.md** — implementation plan and task breakdown
- **CLAUDE.md** — guidance for Claude Code when working in this project
